### v2.5 対象項目

#### JAL航空運賃の表示改善

2026-07-30の検証では、本番`data/timetable.json`にJAL便が10件（大阪（伊丹）線8件、出雲線2件）あり、全件で`price`が未設定だった。また、[`useRouteSearch.ts`](../../src/composables/useRouteSearch.ts)はJAL便の運賃を明示的に`0`としており、[`transit.vue`](../../src/pages/transit.vue)は`0`を「料金不明」と表示する。JAL便から空港連絡バスへ乗り継ぐ経路では、経路ヘッダーの`¥520`が全行程の合計に見える一方、実際には空港連絡バスだけの運賃である。

完了時は、航空運賃が未登録または変動することと、無料・徒歩・取得失敗を区別し、利用者が表示金額を全行程の確定総額と誤認しないこと。

- [ ] 航空運賃の表示仕様を確定する。最低限、`確定額あり`、`変動運賃・別途`、`取得不能`、`無料`、`徒歩`を区別する。
- [ ] JAL便の`price`が未設定の場合、区間運賃を「航空運賃は別途（変動）」等の誤解のない表現へ変更する。
- [ ] JAL便を含む経路のヘッダーと到着行を「¥520 + 航空運賃」等の表示にし、空港連絡バスだけの金額を全行程の確定総額として表示しない。
- [ ] JAL便の`price`が登録されている場合は、その金額を区間運賃と経路合計へ反映する。
- [ ] `0`を不明値として使う実装を廃止または正規化し、徒歩・無料・未登録運賃を型または状態値で区別する。
- [ ] 料金順ソートで、変動運賃を含む経路を既知部分の金額だけで「最安」と誤認させない仕様を決定して実装する。
- [ ] 経路マップ、検索履歴、お気に入り、共有URLなど、乗換検索結果を再表示する導線でも同じ運賃状態を維持する。
