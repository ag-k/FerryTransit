# JAL航空運賃の表示・データ運用方針

## 方針

- JAL航空運賃は予約時期、空席、運賃種別などで変動するため、FerryTransitでは固定額を継続管理しない。
- 公開時刻表のJAL便は`price`を未設定とし、クライアントでは「航空運賃は別途（変動）」と表示する。
- JAL便と固定運賃交通を組み合わせた経路は、既知額を「¥520 + 航空運賃（変動）」のように表示する。
- 将来、検証済みの運賃を登録する場合のみ、`price`へ正の数を設定する。`0`、負数、文字列は登録しない。

## 状態の定義

| 状態 | データ | 表示 |
| --- | --- | --- |
| 確定額あり | 正の`price`または運賃マスタの正の金額 | `¥12,340` |
| 変動運賃・別途 | JAL便の`price`未設定 | 航空運賃は別途（変動） |
| 取得不能 | JAL以外で有効な運賃を解決できない | 料金不明 |
| 無料 | 明示的な無料状態 | 無料 |
| 徒歩 | 徒歩区間 | `-` |

## 並び替え

料金順では、確定額・無料・徒歩だけの経路、変動運賃を含む経路、取得不能を含む経路の順に並べる。変動運賃を含む経路は、既知部分の金額だけを使って最安扱いにしない。

## 更新・検証

- 更新責任者: リリース時刻表データの担当者
- 適用期間: 各JAL tripの`start_date` / `end_date`
- 一次情報: [JAL国内線運賃](https://www.jal.co.jp/jp/ja/dom/fare/rule/index.html)、[隠岐発の航空券検索](https://www.jal.co.jp/domestic/ja-jp/flights-from-oki)
- ローカル検証: `npm run timetable:validate:jal-fares`
- 公開時検証: 時刻表のbuild・publish処理で同じ検査を自動実行する。

管理画面の編集、CSV/JSONインポート、公開JSON生成、Storage配信では、正の`price`が設定された場合にその値を保持する。未設定の場合は値を補完せず、変動運賃として扱う。
